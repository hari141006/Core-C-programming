
## 01_basics

#### Introduction to C
- C is a general-purpose programming language.
- It was developed by Dennis Ritchie.
- C is fast, efficient, and portable.
- It provides direct access to memory using pointers.
- It is widely used in embedded and system programming.

#### Basic Syntax
- C programs are made up of statements and functions.
- Each statement usually ends with a semicolon `;`.
- C is case-sensitive.
- Curly braces `{ }` define blocks of code.
- Every C program normally starts execution from `main()`.

#### Program Structure
- A C program can contain header files, functions, and statements.
- Header files provide declarations for library functions.
- The `main()` function is the starting point of execution.
- Statements inside `main()` perform the required operations.
- `return 0;` indicates successful program termination.

#### Comments
- Comments are used to explain the code.
- The compiler ignores comments during compilation.
- Single-line comments start with `//`.
- Multi-line comments are written between `/*` and `*/`.
- Comments make programs easier to understand and maintain.

#### Compile and Run C Programs
- C source code is normally saved with the `.c` extension.
- A compiler converts C source code into executable code.
- GCC is a commonly used C compiler.
- The compiled program can then be executed from the terminal.
- The basic process is: **Write → Compile → Run → Test**.
